## :dart: O guia para alavancar a sua carreira

> Raspberry Pi é o computador de placa única mais popular do mundo: por menos de 100 dólares você tem um Linux completo, GPIO para eletrônica, câmera, aceleração de IA e conectividade de sobra — usado tanto por quem está aprendendo a programar quanto por profissionais rodando servidores, automação residencial e visão computacional em produção. Este guia reúne documentação oficial, sistemas operacionais e distribuições, cursos, livros, canais, ferramentas para automação e desenvolvimento, projetos práticos e um capítulo dedicado a IA embarcada (Raspberry Pi AI Camera, AI HAT+ e modelos rodando localmente na placa) — tudo verificado e organizado para quem quer sair da instalação do sistema até projetos reais, por hobby ou como profissional de hardware e sistemas embarcados. Se o seu interesse é o microcontrolador Arduino ou o ecossistema mais amplo de IoT, veja os guias irmãos [Guia de Arduino](https://github.com/arthurspk/guiadearduino) e [Guia de IoT](https://github.com/arthurspk/guiadeiot).

## 🤖 IA na prática

Desde o Raspberry Pi 5, a Raspberry Pi Foundation passou a vender acessórios oficiais de aceleração de IA (AI Camera e AI HAT+), o que muda o tipo de projeto viável na placa: modelos de visão computacional e machine learning rodando localmente, sem depender de nuvem. Use IA generativa para acelerar o aprendizado e a escrita de código, mas lembre-se de que o hardware final é limitado — sempre teste no dispositivo real antes de confiar no resultado.

**Para aprender**
- Peça para uma IA explicar, linha a linha, um script Python de exemplo que lê um sensor via GPIO antes de copiar e colar, para entender o que cada biblioteca e cada pino fazem.
- Cole uma mensagem de erro do sistema (ex.: falha ao montar o cartão SD, erro de permissão em `/dev/gpiomem`) e peça para a IA explicar a causa mais provável antes de sair testando comandos aleatórios.
- Peça exercícios com gabarito sobre o tópico que está estudando (GPIO, I2C, systemd, redes, contêineres) para fixar o conteúdo além dos tutoriais prontos.

**Para trabalhar**
- Assistentes como o [GitHub Copilot](https://docs.github.com/en/copilot) ajudam a escrever scripts Python e serviços mais longos, sugerindo funções e identificando erros de sintaxe antes mesmo de rodar.
- A [Raspberry Pi AI Camera](https://www.raspberrypi.com/documentation/accessories/ai-camera.html) roda modelos de visão computacional diretamente no sensor de imagem, sem sobrecarregar o processador principal da placa.
- O [Raspberry Pi AI HAT+](https://www.raspberrypi.com/documentation/accessories/ai-hat-plus.html) adiciona uma NPU dedicada ao Raspberry Pi 5 para rodar modelos de IA localmente, sem depender de nuvem.
- O [LiteRT (sucessor do TensorFlow Lite)](https://developers.google.com/edge/litert) é o framework de referência do Google para rodar modelos de machine learning em dispositivos com poucos recursos, incluindo Raspberry Pi.
- O [Coral](https://developers.google.com/coral) oferece aceleradores USB e módulos de IA da Google, compatíveis com Raspberry Pi para inferência mais rápida.
- O [OpenCV](https://github.com/opencv/opencv) é a biblioteca de referência para visão computacional, base da maioria dos projetos de reconhecimento de imagem em Raspberry Pi.

**Limites e boas práticas**
- IA erra nomes de pinos e comandos específicos de modelos diferentes de Raspberry Pi (a numeração de GPIO muda entre revisões). Confirme sempre na [documentação oficial](#-documentação-oficial) antes de aplicar um comando sugerido.
- Cuidado redobrado com sugestões de IA para comandos que mexem em partição, `fdisk`, permissões do sistema ou serviços expostos à internet — revise manualmente antes de executar em um dispositivo de produção.
- Nunca cole senhas de Wi-Fi, chaves de API de serviços em nuvem ou credenciais de acesso remoto (SSH, Raspberry Pi Connect) em ferramentas de IA sem necessidade.
- Entenda o que você aceita: em um projeto profissional ou numa entrevista técnica, o código é seu, não da IA.

- [r/raspberry_pi (Reddit)](https://www.reddit.com/r/raspberry_pi/) — Uma das maiores comunidades internacionais sobre Raspberry Pi, com projetos, dúvidas e discussões técnicas.
- [r/RASPBERRY_PI_PROJECTS (Reddit)](https://www.reddit.com/r/RASPBERRY_PI_PROJECTS/) — Comunidade focada especificamente em mostrar projetos concluídos com Raspberry Pi.
- [r/homeassistant (Reddit)](https://www.reddit.com/r/homeassistant/) — Comunidade sobre Home Assistant, uma das aplicações mais populares rodando em Raspberry Pi para automação residencial.
- [RoboCore](https://www.robocore.net/) — Loja e comunidade brasileira de robótica, com suporte técnico e conteúdo educacional sobre Raspberry Pi.

## 🚨 Como contribuir

Toda contribuição passa por revisão. Antes de sugerir um recurso, leia o [`CONTRIBUTING.md`](./CONTRIBUTING.md) — resumo rápido: link funcionando (HTTP 200), conteúdo legal, descrição de 1 linha. Reporte links quebrados ou sugira recursos abrindo uma [issue](https://github.com/arthurspk/guiaderaspberry/issues/new/choose).
